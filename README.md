# Stardust

A formation shoot 'em up with the soul of the 2000s shareware classics, written in Rust with
[macroquad](https://macroquad.rs). Your ship only moves sideways, every tap of the fire button is a burst,
and the crystals you collect buy stronger and stronger weapons between sectors.

- **100-level campaign** (20 sectors of 5 levels) with a steep difficulty curve and checkpoints at levels
  26, 51 and 76. Every level is different: its own formation (chevron, ring, spiral, star...), its own
  way of moving, entry paths, featured enemy, diving style and salvos. Bonus stages and boss fights
  change from sector to sector too.
- **Mouse support** in every menu, with the game's own cursor.
- **Local co-op for two players**: two gamepads, keyboard plus gamepad, or both on one keyboard.
- **Gamepad support** (Xbox, PlayStation and generic controllers) in menus and in game.
- Heavy weapons such as **Fireball**, **Plasma**, **Railgun** and **Meteor**, each with its own sound.
- **Weapon evolution:** once a weapon reaches level 5, the shop offers to evolve it (the Fireball becomes a
  mini sun, the Railgun fires twin beams, the Blaster a seven-way fan...).
- A theme song for every region of the campaign.
- Hints show key caps on the keyboard and colored buttons on a gamepad, following the last device used.
- Elite enemies in the later levels (Armored, Healer, Mirror, Leader) and boss fights that change the
  stage: darkness, rising ground and meteor showers.
- Co-op **DUO BEAM** and a one-time rescue for a fallen partner.
- Challenge ships unlocked by campaign feats.
- Dynamic lighting, deep parallax backgrounds, gamepad vibration and fully remappable controls for both
  players.

All art (pixel art written as text plus vector icons) and all music (synthesized chiptune) are generated by
the code, so the game ships as a single executable. The fonts (`assets/fonts`, OFL license) are embedded in the
binary. The game renders at the monitor's physical resolution (4K included), so text and art stay sharp at
any size or Windows scaling. Fullscreen (F11 or Alt+Enter) stays on the monitor the window is on.

Languages: **English** and **Português (Brasil)** (Settings > Game > Language). The game picks the system
language on first launch.

Current version: **0.1.0** (early stage).

## Running

```bash
cargo run --release
```

On Linux, install the audio and video libraries first:

```bash
sudo apt install libasound2-dev libx11-dev libxi-dev libgl1-mesa-dev libudev-dev
```

## Controls

| Action | Keyboard | Gamepad |
|---|---|---|
| Move | ← → or A D | left stick / D-pad |
| Fire (tap) | Space or Z | A / RT |
| Bomb | X or G | X / B |
| Ship ability | C or H | Y / RB |
| Precision | Shift | LB |
| Pause | Esc or P | Start |

Every game key and button can be remapped, separately for each player, in *Settings > Controls*.

**Co-op:** choose *PLAYERS: 2* on the game mode screen; player 2 picks any ship player 1 has unlocked.
With no gamepad, player 1 uses A D, Space/Z, X/G, C/H and left Shift, and player 2 uses the arrows, `,` (or
Right Ctrl), `.` (Numpad 2), `/` (Numpad 3) and right Shift. With one gamepad, player 1 is on the keyboard and player 2 on the gamepad; with two, each player
takes one. Both ships share the score, the crystals and the shop; each has its own lives and bombs.

## Building for Windows

On Windows:

```bash
cargo build --release
```

The executable ends up in `target\release\stardust.exe`, with icon and version info (via `build.rs`).
For the installer, open `installer/stardust.iss` in [Inno Setup 6](https://jrsoftware.org/isinfo.php) and
click *Compile*.

Cross-compiling from Linux (requires `gcc-mingw-w64-x86-64`):

```bash
rustup target add x86_64-pc-windows-gnu
cargo build --release --target x86_64-pc-windows-gnu
```

## Quick tweaks

- **Difficulty:** `Difficulty` in `progress.rs` (pace, fire rate and bullet speed); the per-level curve is
  in `Game::stage` (`game.rs`).
- **Boss health:** `Boss::new` (`boss.rs`).
- **Shop prices:** `Item::price` (`game.rs`); weapon tiers in `Weapon::tier` (`ships.rs`).
- **Translations:** `src/i18n.rs`. Every string drawn on screen goes through `i18n::tr`, which maps the
  English text (or a template such as `SECTOR {}`) to Portuguese.
- **Music:** constants in `audio.rs`. Each bar has 16 steps; `-` holds the note and `.` is a rest.

## Command line options

- `--export-music` writes the soundtrack to `exported_music/*.wav`.
- `--export-icon <folder>` writes the icon as PNG (16 to 256 px).

## Custom music

Put `.ogg` or `.wav` files named `title`, `stage`, `boss`, `shop`, `final`, `credits`, `region1` to
`region8` (one per campaign region) and `special` in a `music` folder next to the executable (or inside the
save folder). The soundtrack is composed on worker threads: the game starts as soon as the title theme is
ready and the other songs arrive in the background.

## Development build

Test tools (a bot that plays by itself, god mode, opening screens directly) only exist with the `dev` feature:

```bash
cargo run --release --features dev
```

| Variable | Effect |
|---|---|
| `STARDUST_AUTOPLAY=1` | a bot plays by itself |
| `STARDUST_GOD=1` | 99 lives and weapon at level 5 |
| `STARDUST_WAVE=N` | start at wave N (in the campaign, wave = level) |
| `STARDUST_COOP=1` | two-player co-op (the bot flies both ships) |
| `STARDUST_DUO=1` | co-op with the duo beam always on |
| `STARDUST_SCENE=0..2` | boss fights start in darkness, rising ground or meteor shower |
| `STARDUST_NOFIRE=1` | the bot does not shoot (to look at formations) |
| `STARDUST_EVOLVE=1` | the starting weapon begins evolved at level 5 |
| `STARDUST_PADHINTS=1` | hints always show gamepad buttons |
| `STARDUST_PROFILE=1` | prints CPU time per frame and slow frames |
| `STARDUST_RESIZE=1` | resizes the window to 4K after 4 s (fullscreen test) |
| `STARDUST_FONTBENCH=1` | measures font rebuilds and exits |
| `STARDUST_EASYBOSS=1` | bosses with 5% health |
| `STARDUST_XP=N` | start with N experience |
| `STARDUST_MODE=0..5` / `STARDUST_DIFF=0..3` | mode and difficulty used by the bot |
| `STARDUST_WEAPON=N` / `STARDUST_SHIP=N` | starting weapon and ship |
| `STARDUST_SCREEN=...` | open a screen directly (`help`, `cards`, `settings`, `hangar`, `archives`, ...) |

With `dev`, any on-screen text missing from the translation table is printed to stderr as `I18N-MISS`
while the game runs in Portuguese.

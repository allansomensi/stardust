# Stardust

A formation shoot 'em up with the soul of the 2000s shareware classics, written in Rust with
[macroquad](https://macroquad.rs). Your ship only moves sideways, every tap of the fire button is a burst,
and the crystals you collect buy stronger and stronger weapons between sectors.

All art (pixel art written as text plus vector icons) and all music (synthesized chiptune) are generated by
the code, so the game ships as a single executable. The fonts (`assets/fonts`, OFL license) are embedded in the
binary. The game renders at the monitor's physical resolution, so text stays sharp at any Windows scaling.

Languages: **English** and **Português (Brasil)** (Settings > Game > Language). The game picks the system
language on first launch.

Current version: **0.1.0** (early stage).

## Running

```bash
cargo run --release
```

On Linux, install the audio and video libraries first:

```bash
sudo apt install libasound2-dev libx11-dev libxi-dev libgl1-mesa-dev
```

## Building for Windows

On Windows:

```bash
cargo build --release
```

The executable ends up in `target\release\stardust.exe`, with icon and version info (via `build.rs`).
For the installer, open `installer/stardust.iss` in [Inno Setup 6](https://jrsoftware.org/isinfo.php) and
click *Compile*.

Cross-compiling from Linux (requires `gcc-mingw-w64-x86-64`):

```bash
rustup target add x86_64-pc-windows-gnu
cargo build --release --target x86_64-pc-windows-gnu
```

## Project layout

| File | Contents |
|---|---|
| `src/main.rs` | window, input, menus, settings, prologue, side panels, achievements and ranks |
| `src/game.rs` | the run itself: modes, waves, dives, weapons, abilities, power-ups, shop, continues |
| `src/game/encounters.rs` | sector events, contracts, fever, special enemies and flight logs |
| `src/game/rifts.rs` | curses, advanced weapons, rifts, ships and trails, Expedition blessings |
| `src/game/arcade.rs` | tap-to-fire trigger, charged shot, firepower, shop items, letters and bonuses |
| `src/game/minigame.rs` | the rift minigames |
| `src/boss.rs` | bosses, with destructible parts and bullet patterns |
| `src/i18n.rs` | Brazilian Portuguese translation table (the game text is written in English) |
| `src/icons.rs` | hand-drawn weapon icons |
| `src/progress.rs` | modes, difficulties, ranks, insignias, achievements, bestiary and logs |
| `src/ships.rs` | ships and weapons (power tiers) |
| `src/art.rs`, `src/sprites.rs` | pixel art (each letter is a palette color) |
| `src/audio.rs` | sound effects and the chiptune mini-sequencer |
| `src/cards.rs` | collectible cards and their effects |
| `src/fx.rs` | particles, backgrounds and graphics quality |
| `src/save.rs` | plain-text save file |
| `src/ui.rs` | TTF fonts per pixel scale, text and panels |

## Quick tweaks

- **Difficulty:** `Difficulty` in `progress.rs` (pace, fire rate and bullet speed).
- **Boss health:** `Boss::new` (`boss.rs`).
- **Shop prices:** `Item::price` (`game.rs`); weapon tiers in `Weapon::tier` (`ships.rs`).
- **Translations:** `src/i18n.rs`. Every string drawn on screen goes through `i18n::tr`, which maps the
  English text (or a template such as `SECTOR {}`) to Portuguese.
- **Music:** constants in `audio.rs`. Each bar has 16 steps; `-` holds the note and `.` is a rest.

## Command line options

- `--export-music` writes the soundtrack to `exported_music/*.wav`.
- `--export-icon <folder>` writes the icon as PNG (16 to 256 px).

## Custom music

Put `.ogg` or `.wav` files named `title`, `stage`, `boss`, `shop`, `final` and `credits` in a `music`
folder next to the executable (or inside the save folder).

## Development build

Test tools (a bot that plays by itself, god mode, opening screens directly) only exist with the `dev` feature:

```bash
cargo run --release --features dev
```

| Variable | Effect |
|---|---|
| `STARDUST_AUTOPLAY=1` | a bot plays by itself |
| `STARDUST_GOD=1` | 99 lives and weapon at level 5 |
| `STARDUST_WAVE=N` | start at wave N |
| `STARDUST_EASYBOSS=1` | bosses with 5% health |
| `STARDUST_XP=N` | start with N experience |
| `STARDUST_MODE=0..5` / `STARDUST_DIFF=0..3` | mode and difficulty used by the bot |
| `STARDUST_WEAPON=N` / `STARDUST_SHIP=N` | starting weapon and ship |
| `STARDUST_SCREEN=...` | open a screen directly (`help`, `cards`, `settings`, `hangar`, `archives`, ...) |

With `dev`, any on-screen text missing from the translation table is printed to stderr as `I18N-MISS`
while the game runs in Portuguese.
